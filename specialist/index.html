How a Telstra order moves through ODO

Read left to right: capture the order, decompose it, persist it, run it on Kubernetes, then keep production healthy.

1 · Capture A Telstra commercial order (mobile, broadband, activation) enters the platform.

2 · ODO Java, Spring Boot, REST APIs, Spring JPA, and EhCache split that order into fulfillment steps and run them.

3 · State PostgreSQL/MySQL hold order state; Kafka signals the next fulfillment work.

4–5 · Run & operate Docker/Helm on EKS then AKS; Graviton −40%, ECK −20%, Veracode −80%, +30% speed, prod AU/MX.
